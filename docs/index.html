KifuLens
プライバシーポリシー

iPhoneで、NAGISAを。

KifuLensは、自作の将棋AI「NAGISA」をスマートフォンで動かし、棋譜・解析結果・定跡・前例を閲覧するためのアプリです。

NAGISA v3 / v4による解析は端末内で行います。解析のために棋譜や局面をサーバーへ送信することはありません。

ソースコードの公開を準備しています。現在のGitHubリポジトリには、この案内ページとプライバシーポリシーだけを掲載しています。

主な機能

  • 棋譜ファイル、テキストの貼り付け、HTTPSのCSA URLからの読み込み
  • 端末内での局面解析と、評価値・読み筋の表示
  • 大きな定跡ファイルの閲覧と、Floodgateの前例検索
  • 前例DBだけのダウンロード・更新。取得後はオフラインで利用可能

前例DBの更新について

KifuLens Precedent Updaterは、運営者が前例DBを作成し、Google Driveへ配布するための専用ツールです。公開されたFloodgateの棋譜から前例DBを作り、DBファイルと更新情報を配布フォルダへ保存します。

Googleアカウントでの認証は、運営者の更新ツールだけが使用します。KifuLensの利用者が前例DBをダウンロードする際に、GoogleへのログインやDriveへのアクセス許可は必要ありません。

更新ツールが扱う情報と権限の範囲は、プライバシーポリシーをご覧ください。
